# 清笔（QingBi）

AI 小说写作助手 — 本地优先、数据自持的桌面写作工具。写小说、记灵感、AI 辅助、统计码字，一个应用全搞定。

**人是作者，AI 是助理**：所有 AI 能力按需触发、单次小调用；出场统计、字数、预过滤等一律本地规则实现，日常写作零 token 消耗。

## 特性

### 写作核心
- 📁 **章节管理**：文件树管理章节，自然排序（第1章 < 第2章 < 第10章），支持拖拽、收藏、重命名；多项目库切换
- ✍️ **沉浸编辑器**：CodeMirror 6，衬线字体预览、打字机模式、聚焦行、字号/行距/宽度调节、查找替换、按文件保留撤销历史、自动感知外部修改
- 🗂 **多标签编辑**：同时打开多章、标签持久化（重启后恢复）、未保存提示
- 🔍 **全文搜索**：文件名 + 内容双通道，近期文件快捷入口
- 🗑 **回收站**：删除的文件先进 `.trash`，可恢复或清空（与历史版本形成双保险）
- 📤 **导入导出**：拖入外部文件/文件夹导入（总量 500MB 上限）、合并导出 EPUB3 / Markdown / 纯文本

### 历史与数据安全
- 💾 **自动备份**：每次保存自动备份（内容不变自动去重、同名保留 20 份），重命名/移动章节后历史版本仍可查
- ⏱ **历史版本**：备份列表 + 与当前内容逐行 diff 对比 + 一键恢复
- 🛡 **路径沙箱**：所有文件命令经项目根目录校验（fail-closed），保存竞态防护（写盘期间继续输入不回退）

### AI 辅助（按需触发、低消耗）
- 🤖 **AI 对话**：全屏对话 + 侧边面板双形态，流式输出，多会话管理，支持 OpenAI / Claude / DeepSeek，友好错误提示（401/429/网络/超时）
- ⚡ **快捷操作**：续写 / 润色 / 扩写 / 检查 / 摘要 / 大纲 / 起名，每个提示词可在设置中覆盖
- 🔀 **Diff 应用**：AI 结果 word 级逐块对比，手动接受 / 拒绝 / 插入编辑器
- 🧠 **上下文注入**：角色设定 / 大纲 / 项目概述 / 前情提要按需开关，总量预算截断、显示估算用量；前情优先读摘要库，缺省退化为章尾片段
- 📚 **摘要库**：章节摘要一键存库，自动作为前情注入后续写作
- 🔎 **一致性检测**：人物 / 大纲变化自动检测——累计字数触发、本地预过滤（角色名匹配）、结构化 JSON 结果、确认后写回设定文件
- 🎴 **角色卡片**：设定自动进入 AI 上下文；零 token 出场统计（正文出现次数 + 最近章节）；「从本章抽取」手动提取新角色名（单次小调用，AI 提议、人决定）

### 统计与激励
- 📊 **写作统计**：今日字数、目标进度、连续天数、码字日历、写作计时（今日累计，跨重启保留）；AI 应用改动同样计入统计

### 外观
- 🎨 **主题**：12 套深浅色主题预设（每个主题有独立色调，设置里可实时预览），统一设计令牌（CSS 变量）

## 技术栈

- Tauri 2（Rust 后端）
- Vue 3 + Pinia + TypeScript
- CodeMirror 6
- Tailwind CSS + 设计令牌（CSS 变量）

## 开发

```bash
# 安装依赖
npm install

# 启动开发模式（桌面应用）
npm run tauri dev

# 前端单独开发（Vite，仅浏览器）
npm run dev

# 类型检查 + 前端构建
npm run build

# Rust 后端检查
cd src-tauri && cargo check

# 打包
npm run tauri build

# 单元测试（字数统计 / 行级 Diff / 角色抽取解析）
npm test
```

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |
| `Ctrl+B` | 切换文件树 |
| `Ctrl+J` | 切换 AI 面板 |
| `Ctrl+P` | 搜索文件 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+Shift+A` | 全屏 AI 对话 |
| `Esc` | 关闭弹窗 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换标签 |
| `Ctrl+=` / `Ctrl+-` | 调大 / 调小编辑器字号 |

Mac 上 `Ctrl` 对应 `⌘`（均支持）。

## 数据存储

所有数据保存在本地项目文件夹内：

- 章节文件：`.md` / `.txt` 文件
- 角色卡片：`角色/`（每个角色一个 `.md`，自动注入 AI 上下文）
- 大纲：`大纲/`
- 章节摘要：`.summaries/`
- 项目概述（可选）：`_project.md`
- 写作统计：`.stats/stats.json`
- 检测结果：`.stats/consistency.json`
- 自动备份：`.backups/`
- 聊天记录：`.chatlog/`
- 回收站：`.trash/`
- 应用配置：系统应用数据目录下的 `config.json`（不含密钥）
- API Key：系统钥匙串（Windows 凭据管理器 / macOS Keychain），不落明文磁盘
